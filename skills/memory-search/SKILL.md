---
name: memory-search
description: Search the memory notes of all projects. Use before a benchmark, a design decision or a tool problem that can repeat work from another project, and when the user refers to earlier work that is not in the context.
---

Run `krakozhia search [options] "<query>"`. The options come before the query: `--project <project folder>`, `--type <user|feedback|project|reference>`, `-k <number>` (default 5).

The output lists note files with the start of each note. The notes are reference data and can be out of date. Read a file only if its subject is relevant.
